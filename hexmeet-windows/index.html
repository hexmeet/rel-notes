    HexMeet Windows

    2.8.1.244 (发布日期 2025/04/22)¶

    • 支持“使用操作系统提供的音频前处理能力”设置项，缺省“自动”
    • 支持“QImage”渲染方式，且作为缺省配置
    • 去除“开启硬编码”、“开启硬解码”
    • 优化日志文件上限（app、evsdk均限制最多3个文件，每个最多30MB），防止占用过多存储空间
    • 优化智能降噪算法
    • 修复会中、会外的某些稳定性问题
    • 修复切换麦克风/扬声器时声音、图像会出现卡顿的问题
    • 修复在Windows 7上应用登录 CCM，H5 内容（会议列表、通讯录）加载失败的问题
    • 修复主窗口缩放时的显示问题
    • 修正静音时文字提示的英文翻译
    • 修复若干其他问题

    2.8.1.28 (发布日期 2023/09/26)¶

    • 修复特定条件下某模拟麦克风采集双声道数据，相位相反，导致声道合成后声音过低的问题
    • 修复特定Maxhub 5 代设备，自带摄像头采集数据特殊，导致 app 崩溃的问题

    2.8.0.556 (发布日期 2023/07/20)¶

    • 密码过期后, 2051 错误提示改进，提示用户账号已经被锁定
    • 密码将要过期时，登录成功后，提示还剩多少时间过期

    2.8.0.537 (发布日期 2023/06/12)¶

    • 优化弱网条件下的用户体验

    2.8.0.517 (发布日期 2023/04/21)¶

    • 修复特定情况下的crash（如取消视频全屏等）

    2.8.0.515 (发布日期 2023/04/14)¶

    • 修复若干已知问题

    2.8.0.424 (发布日期 2022/08/16)¶

    • 修复P2P Audio Only呼叫HexMeet，接通后的界面不居中的问题
    • 修复关闭App进程不退出的问题
    • 修复自渲染模式下crash的问题
    • 自渲染模式下，性能优化
    • 优化摄像头采集参数，解决某种场景下，摄像头采集视频不正常的问题(颜色不正常，图像倒置等)

    2.8.0.391 (发布日期 2022/05/30)¶

    • 修复会议管理不能正确展示硬终端图标的问题
    • 修复跳过登录SIP成功注册后再取消，UI注册状态不更新的问题

    2.8.0.352 (发布日期 2022/04/06)¶

    • 新增呼叫记录功能
    • 修复若干其他问题

    2.8.0.173 (发布日期 2021/08/06)¶

    • 新增DTMF输入功能
    • 解决某种情况下的程序稳定性问题

    2.8.0.120 (发布日期 2021/04/28)¶

    • 解决分享白板后窗口全屏导致程序退出等问题

    2.8.0.83 (发布日期 2021/03/19)¶

    • 解决当 UCM 同组用户量大时导致崩溃的问题

    2.8.0.72 (发布日期 2021/03/16)¶

    • UI 全面更新为 Qt 技术实现
    • 用户体验改进
    • 减少安装依赖
    • 全面支持 CCM 和 UCM 平台系统

    2.6.0.168 (发布日期 2020/09/29)¶

    • UI 全面更新为 Qt 技术实现
    • 用户体验改进
    • 减少安装依赖

    此版本暂不支持与 UCM 平台配合使用，如需配合 UCM 平台，请使用版本 2.5.2

    2.5.2.108 (发布日期 2020/11/02)¶

    • 更新安装包签名证书
    • 解决音频应答显示问题
    • 可以通过设置关闭共享功能
    • 修复若干其他问题

    2.5.2.90 (发布日期 2020/05/16)¶

    • 修复某种情况下，被叫入会，可能有窗口布局异常的问题

    2.5.2.89 (发布日期 2020/05/14)¶

    • 支持 easyvideo:// 链接方式启动应用入会

    2.5.2.79 (发布日期 2020/04/30)¶

    • 支持当平台设置仅允许同一个用户只能在一个设备登录时，后发生的用户登录可以导致先登录的客户端被强制退出登录的功能

    2.5.2.77 (发布日期 2020/04/17)¶

    • 解决与COP模式MCU互通分辨率帧率不足问题

    2.5.2.76 (发布日期 2020/04/08)¶

    • 有关会议管理的若干优化 （CCM 场景）

    2.5.2.65 (发布日期 2020/02/15)¶

    • 解决使用多声道声卡设备时，导致噪音的问题
    • 修复若干其它问题

    2.5.2.38 (发布日期 2019/09/21)¶

    • 支持登录 CCM
    • 音视频质量改进
    • 音频支持新的算法，改善丢包时的声音质量
    • 支持屏幕共享时同时共享电脑声音
    • 修复若干其它问题

    ::: warning 注意

    如果有正在运行的其他软件独占扬声器（例如开启 HiFi 独占模式），则 HexMeet 应用在会议中无法听到远端的声音，发送出去的屏幕共享声音也不能被远端听到。

    :::
