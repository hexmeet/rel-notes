    会捷通 Windows

    2.0.0.315、2.1.0.218-64 (发布日期 2025/09/20)¶

    • 支持1080p30双流发送
    • 支持分屏/固定轮询固定窗口位置
    • 支持对端讲话时的语音实时转写和翻译
    • 支持平台自定义的网络设备管理服务（NDM）
    • 修复其他应用窗口覆盖在被共享应用窗口上方也被共享出去的问题
    • 修复回退问题：初次登录修改密码不工作、被共享应用窗口标题遮挡共享控制栏
    • 修复在线更新版本确定安装按钮未屏蔽重复点击，导致更新失败的问题
    • 修复来电邀请接听按钮未屏蔽重复点击导致进不到视频窗口的问题
    • 修复白板被动停止后，重新发送遗留历史批注的问题
    • 修复接收白板时选定视频，取消选定后白板窗口比例错误的问题
    • 修复若干其他已知问题

    2.0.0.258、2.1.0.130-64 (发布日期 2025/05/24)¶

    • 支持人脸签到
    • 智能降噪算法缺省档“高”回退至2024/10，解决MaxHub上讲话卡顿的问题
    • x64版本去除对Visual C++ Redistributable运行时的依赖
    • 修复启动应用时多次点击图标，可能出现两个或多个会捷通同时运行的问题
    • 修复终端侧会议管理与会者列表有时刷新失败
    • 修复反复打开选择共享内容窗口桌面“屏幕1”、“白板”缩略图及文字会自动缩小的问题
    • 修正静音时文字提示的英文翻译
    • 修复白板被动停止后，重新发送白板遗留之前的白板批注

    2.1.0.86-64 (发布日期 2025/03/25)¶

    • （首个x64 (64-bit)的正式发布版本）
    • 支持 Direct3D12 渲染方式（对不支持的老显卡不可见）
    • 支持入会前弹出升级提醒，点击下载后即可安装
    • 改进降噪和啸叫抑制算法，降低CPU消耗
    • 优化文字提示的展示和淡出效果，做到足够平滑
    • 优化下载远端头像超时时长为18秒，最多重试10次
    • 优化应用覆盖安装时，默认保持原安装路径；（针对自定义安装路径）
    • 修复系统普通账户“以管理员身份运行”安装会捷通不能在桌面生成快捷方式的问题
    • 修复会议/通讯录页面在某场景未自适应最大化窗口的回退问题
    • 修复上报MAC地址有误或未上报的问题
    • 修复尝试快速发送带格式的消息内容可能会崩溃的问题
    • 修复在4K扩展屏上反复发送白板共享，白板窗口会跑到主屏的问题
    • 修复因某些MAXHUB BIOS中UUID相同，计算出的SN相同，导致应用ID重复的问题
    • 修复MAXHUB上，某输入框选中时无法自动调起系统软键盘的问题
    • 修复若干其他问题

    • 改进降噪和啸叫抑制算法，降低CPU消耗
    • 优化文字提示的展示和淡出效果，做到足够平滑
    • 优化下载远端头像超时时长为18秒，最多重试10次

    • 修复系统普通账户“以管理员身份运行”安装会捷通不能在桌面生成快捷方式的问题
    • 修复会议/通讯录页面在某场景未自适应最大化窗口的回退问题
    • 修复上报MAC地址有误或未上报的问题

    2.0.0.168 (发布日期 2024/11/30)¶

    • 支持啸叫抑制
    • 优化智能降噪，支持低、中、高、增强四个降噪等级
    • 优化网络检测功能，检测过程中支持自动重试，提高检测成功率
    • 修复在某设备上因DPI获取错误导致应用登录后内容显示错位的问题
    • 修复启用背景虚化时反复开关1080p设置会出现崩溃的问题
    • 修复某些操作后应用主窗口可能产生的透屏问题
    • 修复接收被屏蔽的敏感词之后切换界面语言造成崩溃的问题
    • 修复退会时遇到下载头像超时而导致的崩溃问题

    2.0.0.157 (发布日期 2024/11/15)¶

    • 支持Microsoft Edge WebView2，提高应用运行稳定性，降低资源消耗
    • 支持会中“申请主持人”功能
    • 支持TLS1.3
    • 支持平台“deployId”参数，同一平台不区分登录地址实现以登录用户入会
    • 支持会议分享信息中包含多个“SIP接入地址”
    • 优化UI展示，含设置项、会议信息图标、网络状况报告等
    • 修复若干稳定性问题
    • 修复若干UI体验问题

    2.0.0.94 (发布日期 2024/08/20)¶

    • 使用OpenGL渲染的设备，修正对OpenGL版本的判断，增强稳定性
    • （非Intel Iris集显设备）增加“OpenGL ES”渲染方式
    • 修正在大分辨率设备上发送白板窗口比例错误的问题
    • 修复若干其他问题

    2.0.0.83 (发布日期 2024/07/27)¶

    • 优化平台服务地址和SSO域名配置的参数保存和重置规则
    • 修复在某特殊设备上可能误触发kaec导致讲话丢字的问题
    • 修复某些复杂操作后视频工具栏可能与视频窗口分离的问题
    • 修复若干其他问题

    2.0.0.76 (发布日期 2024/07/12)¶

    • 优化系统默认麦克风、扬声器选项显示具体设备名称
    • 优化接收白板时的批注悬浮按钮图标及位置
    • 修复IPv6环境获取不到远端头像的问题
    • 修复发送白板画批注时被挂断再次入会出现崩溃的问题
    • 修复主窗口出现嵌套错位的问题
    • 修复提交意见反馈，重复点击“确定”提交导致应用崩溃的问题
    • 修复若干其他问题

    2.0.0.59 (发布日期 2024/06/14)¶

    • 修复会中切换声音输入/输出设备（耳机耳麦等）视频明显卡顿的问题
    • 修复与Bass30协作时mute/unmute麦克风，视频会出现短暂卡顿的问题
    • 修复结束会议时有概率freeze无响应的问题（em logout failed）
    • 修复链接入会后，默认的平台服务地址被改写的问题
    • 修复本地麦克风audio meter会随着远端讲话而跳动的问题
    • 修复发送白板过程中被结束会议，之后退出应用出现崩溃的问题
    • 修复中文用户、中文安装路径，远端硬终端看其黑背景、无头像的问题
    • 修复内嵌画中画中的本地视频麦克风状态不更新的问题
    • 修复在英文界面下投票窗口未翻译的问题

    2.0.0.42 (发布日期 2024/05/31)¶

    • 会议中参会者关闭摄像头的显示方式优化
    • 支持客户端单设备登录
    • 会议分享信息支持携带直播地址和密码
    • 支持登出后或自动登录失败时自动清除密码
    • 支持以镜像方式显示本地视频
    • 修复共享应用窗口自动暂停需要手动继续的问题
    • 修复最大化窗口退会，再次入会顶部控制栏错位的问题
    • 修复发起共享电脑声音时，远端可能听到短暂噪声的问题
    • 修复若干已知问题

    1.8.5.32 (发布日期 2023/12/21)¶

    • 修复缺少Visual Studio 2019 运行时依赖文件导致应用不能正常启动的问题
    • 修复使用中文安装路径，应用平台服务地址为空的问题

    1.8.5.30 (发布日期 2023/12/19)¶

    由于 Irix Xe 显卡驱动的问题，在使用该显卡的设备上，会议中切换至全屏可能出现崩溃。如果遇到该问题，建议 ： 1. 安装 英特尔® Graphics Driver：31.0.101.4830 。驱动下载地址 https://www.intel.cn/content/www/cn/zh/download/780185/intel-data-center-gpu-flex-series-windows.html 2. 如果安装了上述驱动没有解决问题，建议将渲染方式改为 QImage （改变渲染方式后，需要完全退出应用，并重新启动后生效）

    • 优化会议管理页面加载体验，入会后即自动加载页面
    • 优化应用后台运行时执行卸载先自行退出
    • 优化接收共享时设置1x2，双击远端视频支持选定
    • 优化接收白板时支持“退出批注”操作
    • 优化全屏界面时去除边线
    • 修复退会后从任务栏恢复的最大化窗口为黑屏的问题
    • 修复最小化窗口后点击系统托盘图标无法恢复窗口的问题
    • 修复小方数会议中传统主讲和新型主讲间切换不工作的问题
    • 修复启动窗口边框有重影的问题
    • 修复回退问题：进入会议时全屏显示不工作
    • 修复若干其他问题

    1.8.3.79 (发布日期 2023/09/25)¶

    • 支持关闭窗口自动退到系统托盘，双击图标恢复窗口
    • 支持接收双流时设置1x2布局
    • 调整渲染方式的次序
    • 支持用户名带空格自动截取
    • 修复会控设置画廊且允许终端切换分屏，终端侧无法切换传统主讲的问题
    • 修复接收白板时选定视频，尝试切换布局无“已选定”提示
    • 修复若干其他问题

    1.8.3.52 (发布日期 2023/08/23)¶

    • 登录界面改进，统一云和私有部署入口
    • 登录界面增加“保持登录”开关
    • 支持会场站点名称样式由会议统一管控
    • 支持会议延时提醒，增加延时操作入口
    • 支持消息敏感词过滤（匹配平台v2.0.0）
    • 会议录制控制优化，工具栏增加录制入口
